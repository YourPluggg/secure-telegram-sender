# 🔐 Secure Telegram Sender

Проект для безопасной передачи файлов через Telegram с использованием гибридного шифрования:

* RSA (для шифрования ключа)
* AES (для шифрования файла)

---

## 📦 Состав проекта

```
client/
  app.py                # GUI приложение (Tkinter)
  crypto.py             # Криптография (RSA + AES)
  telegram_sender.py    # Отправка в Telegram

server/
  main.py               # FastAPI сервер

requirements.txt
```

## 💬 Настройка Telegram (ВАЖНО)

Чтобы отправка файлов работала, нужно настроить Telegram-бота.

---

### 1. Создание бота

1. Откройте Telegram
2. Найдите **@BotFather**
3. Напишите команду:

```
/start
```

4. Затем:

```
/newbot
```

5. Укажите:

   * Имя бота
   * Username (должен заканчиваться на `bot`)

6. Получите токен:

```
123456789:ABCDEF...
```

👉 Сохраните этот токен — он понадобится.

---

### 2. Получение chat_id

1. Напишите боту:
   👉 https://t.me/userinfobot

2. Он ответит:

```
Id: 123456789
```

👉 Это ваш `chat_id`

---

### 3. Первый запуск (автонастройка)

При первой отправке файла программа сама попросит:

* `chat_id`
* `bot_token`

И предложит сохранить их в файл:

```
telegram_config.json
```

Пример:

```json
{
  "chat_id": "123456789",
  "bot_token": "123456789:ABCDEF..."
}
```

## 🔑 Как работает система

### Регистрация:

1. Генерируется RSA ключевая пара
2. Публичный ключ отправляется на сервер
3. Сервер сохраняет его

---

### Отправка файла:

1. Получается публичный ключ получателя
2. Генерируется случайный AES ключ
3. Файл шифруется AES
4. AES ключ шифруется RSA
5. Всё отправляется в Telegram

---

### Получение файла:

1. Файл выбирается вручную
2. RSA расшифровывает AES ключ
3. AES расшифровывает файл

---

## 📁 Формат файла

```
[ RSA(KEY) ] ---KEY--- [ AES(DATA) ]
```
